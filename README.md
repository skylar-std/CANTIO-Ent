# CANTIO Entertainment

**엔터테인먼트 공식 홈페이지 디자인 및 웹 개발 프로젝트**

CANTIO Entertainment(이하 **CANTIO Ent.**)는 가상의 엔터테인먼트 회사를 설정하고, **실제 기업의 공식 홈페이지처럼 사용할 수 있는 웹사이트를 직접 기획·디자인·구현하는 포트폴리오 프로젝트**입니다.

이 저장소의 핵심은 별도의 아티스트 브랜딩 자료가 아니라 **CANTIO Ent. 홈페이지 자체의 UI/UX 디자인, 프런트엔드 개발, 반응형 웹 구현 및 배포 과정**입니다. 소속 아티스트의 정보와 콘텐츠는 사이트에 들어가는 구성 요소로 활용합니다.

> **프로젝트 상태:** 홈페이지 설계 및 제작 준비 단계  
> **프로젝트 유형:** 개인 웹 디자인·개발 포트폴리오  
> **안내:** CANTIO Ent.는 포트폴리오를 위한 가상 회사입니다. 실제 기획사 또는 공식 오디션 사이트가 아닙니다.

## 02. 사이트맵 및 페이지 구성

아래 메뉴는 **현재 계획한 정보 구조**이며, 개발 및 디자인 과정에서 조정될 수 있습니다.

```text
CANTIO Entertainment
├── HOME                 메인 비주얼 / 주요 콘텐츠 / 최신 소식
├── COMPANY              회사 소개 / 방향성 / 회사 정보
├── ARTISTS              소속 아티스트 목록
│   ├── MIRREO            걸그룹 상세 / 멤버 / 음악 및 콘텐츠
│   └── RE:DAY            보이그룹 상세 / 멤버 / 음악 및 콘텐츠
├── MUSIC                앨범·싱글 / 발매 정보 / 콘텐츠
├── NEWS                 회사 및 아티스트 소식
└── AUDITION             오디션 안내 UI (가상 콘텐츠)
```

| 페이지 | 주요 디자인·개발 내용 |
| --- | --- |
| **HOME** | 메인 히어로 비주얼, 아티스트 하이라이트, 최신 음악 및 뉴스, 주요 페이지 진입 동선 |
| **COMPANY** | 회사 소개, 시각적 아이덴티티를 반영한 정보 레이아웃 |
| **ARTISTS** | 아티스트 카드 및 목록, 그룹별 상세 페이지, 프로필·콘텐츠 구성 |
| **MUSIC** | 아티스트별 앨범·싱글 아트워크, 발매 정보, 상세 화면 |
| **NEWS** | 공지·새 소식 카드, 목록과 상세 화면 |
| **AUDITION** | 가상 기획사의 오디션 안내 페이지 디자인. 실제 개인정보 수집·지원 접수 기능은 만들지 않음 |

## 03. 아티스트 콘텐츠

아래 그룹은 **CANTIO Ent. 홈페이지의 `ARTISTS` 섹션에 포함할 콘텐츠**입니다. 회사 홈페이지가 프로젝트의 중심이며, 그룹별 디자인 및 음악 기획은 각 상세 페이지에서 소개합니다.

### MIRREO (미레오) — Girl Group

- **형태:** 5인조 AI 가상 걸그룹
- **멤버:** 멀린 · 벨 · 헤이즐 · 로즈 · 애니
- **데뷔 프로젝트:** `MIRR:ERROR`
- **데뷔 싱글:** `STEEL KISS`
- **콘셉트 소재:** 거울, 오류, 이중 자아, 평행세계 등

### RE:DAY (리데이) — Boy Group

- **형태:** 5인조 가상 보이그룹
- **멤버:** 시우 · 지안 · 도현 · 하준 · 아이작
- **앨범 기획안:** `AFTER 4:10`
- **콘셉트 소재:** 청춘, 기록, 기억, 우정
- **비주얼 방향:** Sky Blue + Coral, 캠코더와 사진 등 기록을 연상시키는 요소

※ 위 음악·앨범 정보는 가상 프로젝트의 기획 내용이며, 실제 음원 발매 이력을 뜻하지 않습니다.

## 04. UI/UX 및 디자인 방향

현재 단계에서는 특정 색상이나 레이아웃을 최종 확정하지 않고, 다음 원칙을 기준으로 시안을 발전시킵니다.

1. **홈페이지 중심의 시각적 위계** — 첫 화면에서 CANTIO Ent.라는 회사가 가장 먼저 인식되도록 설계
2. **콘텐츠 중심의 레이아웃** — 이미지, 영상, 아티스트 포스터와 텍스트를 균형 있게 배치
3. **명확한 내비게이션** — 상단 메뉴, 모바일 메뉴, 페이지 간 이동 경로를 일관성 있게 구성
4. **아티스트별 개성 유지** — 공통 사이트 디자인 안에서 MIRREO와 RE:DAY의 서로 다른 분위기를 표현
5. **반응형·접근성 고려** — 읽기 쉬운 텍스트, 명확한 버튼, 키보드 조작, 모바일 가독성 점검
6. **절제된 인터랙션** — 페이지 전환, 호버, 스크롤 효과를 필요에 맞게 구현하고 사용성을 우선
